# Qwen Browser — نسخة أندرويد (APK)

متصفح أندرويد (WebView) بتبويبات وإشارات مرجعية، ومساعد ذكاء اصطناعي يتصل بنموذج Qwen الذي تشغّله أنت. لا مفتاح API ولا اشتراك.

## الحصول على ملف APK

### الطريقة الأسهل: GitHub Actions (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه محتويات هذا المجلد (مع المجلد المخفي `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← انتظر دقائق حتى يكتمل.
3. نزّل الملف `qwen-browser-apk` من أسفل صفحة التشغيل، فك ضغطه وستجد `app-debug.apk`.
4. انقله إلى هاتفك وثبّته (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).

### بديل: Android Studio
افتح المجلد في Android Studio ← **Build ▸ Build APK(s)**. الملف في `app/build/outputs/apk/debug/`.

### بديل: سطر الأوامر
يلزم JDK 17 وAndroid SDK (متغير `ANDROID_HOME`): `./gradlew assembleDebug`

## ربط الهاتف بنموذج Qwen

على الهاتف، `localhost` تعني الهاتف نفسه، فلديك خياران:

1. **النموذج على حاسوبك** (الأسهل): شغّل Ollama ليقبل اتصالات الشبكة:
   `OLLAMA_HOST=0.0.0.0 ollama serve` ثم `ollama pull qwen3:8b`.
   في التطبيق: ✦ ثم ⚙ ثم عنوان الخادم `http://192.168.1.X:11434` (عنوان الحاسوب في الشبكة). يجب أن يكونا على الشبكة نفسها، وقد تحتاج السماح بالمنفذ 11434 في جدار الحماية.
2. **النموذج على الهاتف نفسه** عبر Termux أو تطبيق يشغّل llama.cpp محلياً: استخدم `http://localhost:PORT`. نماذج Qwen الصغيرة (0.5B–3B) هي الواقعية على الهاتف.

التطبيق يسمح بـ HTTP العادي (دون TLS) لأن الخوادم المحلية لا تستخدم شهادات.

## الاستخدام
- `＋` تبويب جديد، `★` إشارة مرجعية (اضغط مطولاً على الإشارة لحذفها)، `✦` المساعد.
- زر الرجوع في الهاتف: يغلق المساعد، ثم يرجع في الصفحة، ثم يغلق التبويب.
- حدّد نصاً في الصفحة ثم افتح المساعد واضغط «شرح المحدد» أو «ترجمة إلى العربية».
- يمكن جعله متصفحاً افتراضياً من إعدادات أندرويد (يتعامل مع روابط http/https).

## غير متضمن في هذه النسخة
التنزيلات داخل التطبيق (تُسلَّم للنظام)، والفيديو بملء الشاشة، والتصفح الخفي، وسجل التصفح، وحفظ التبويبات بعد إغلاق التطبيق.
